## 🚀 Quick Start for Enterprise Users

### 1. Basic Federated Training
```python
from agisfl import FederatedClient

client = FederatedClient(server_url="your-server.com", api_key="your-key")
client.join_training(model=YourModel(), data_loader=your_data, algorithm="FedAvg")
```

### 2. Privacy-Enhanced Training
```python
client.configure_privacy({
    "differential_privacy": {"epsilon": 1.0, "delta": 1e-5},
    "secure_aggregation": {"enabled": True}
})
```

### 3. Custom Algorithm Implementation
```python
class CustomFedAlgorithm(FederatedStrategy):
    def aggregate(self, client_weights, client_sizes):
        return your_custom_aggregation_logic()

client.register_strategy("custom_alg", CustomFedAlgorithm())
```
